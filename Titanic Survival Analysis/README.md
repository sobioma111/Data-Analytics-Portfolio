# Titanic Survival Analysis

## Project Overview
## Dashboard Preview

![Titanic Survival Analysis Dashboard](Dashboard/Screenshot%202026-10-21%20212734.png)
This project explores passenger survival patterns from the Titanic disaster using Microsoft Excel.

## Project Deliverables

- Dashboard preview
- Excel analysis workbook
- Dataset
- Project report
- Presentation

- ## Key Findings

* Total passenger records analysed: 1,309.
* Total survivors: 500.
* Female survivors: 339.
* Overall survival rate: 38.20%.

The dashboard also compares survival patterns by passenger class, age group, gender, and fare range.
