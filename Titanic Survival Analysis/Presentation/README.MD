# Titanic Survival Analysis — PowerPoint Presentation

## Project Overview

This presentation showcases an Excel-based analysis of Titanic passenger survival outcomes, comparing survival patterns across gender, passenger class, and age groups.

## Project Objectives

* Analyze overall passenger survival outcomes.
* Compare survival rates across passenger groups.
* Present key findings through clear, recruiter-friendly visualizations.
* Demonstrate data analysis and data storytelling skills using Microsoft Excel.

## Key Findings

* **Total passenger records:** 1,309
* **Passengers who survived:** 500
* **Passengers who did not survive:** 809
* **Overall survival rate:** 38.20%
* **Gender:** Female passengers had a higher observed survival rate than male passengers.
* **Passenger class:** First-class passengers had a higher observed survival rate than third-class passengers.
* **Age group:** Children recorded the highest survival rate among the displayed age groups.
